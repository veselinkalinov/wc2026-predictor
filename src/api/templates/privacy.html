Privacy Policy

Last updated: June 2026

Welcome to the FIFA 26 PREDICTOR ("the App"). This Privacy Policy explains how we handle information when you use our machine-learning-powered football prediction platform.

1. Information We Collect

This is an open-source, educational project. We collect minimal information:

  • Usage Data: Anonymous server-side logs (IP, browser type, pages visited, timestamps) for performance monitoring. Not linked to personal identities.
  • Prediction Inputs: Team names and match settings are processed server-side to generate results. We do not persistently store individual prediction inputs.
  • No Account Data: No registration required. We collect no names, email addresses, or personally identifiable information.

2. How We Use Your Information

  • Operating and improving the ML prediction engine.
  • Diagnosing server errors and monitoring performance.
  • Understanding aggregate usage patterns.

We do not use data for advertising, profiling, or any commercial purpose.

3. Cookies & Local Storage

The App may use browser local storage to remember UI preferences (e.g. last selected teams). No tracking cookies are set. Google Fonts and Tailwind CDN are loaded from external servers — these providers may set their own cookies.

4. Third-Party Services

  • Google Fonts — Typography assets from Google's CDN.
  • Tailwind CSS CDN — CSS framework from cdn.tailwindcss.com.
  • Scikit-Learn / Python — All ML inference is server-side; no data is sent to external ML providers.

We do not sell, rent, or trade information with third parties.

5. Data Retention

Server access logs are retained for a maximum of 30 days then automatically purged.

6. Security

We take reasonable technical measures to protect the App. No internet-based system is completely secure. This App is educational and should not be used to process sensitive personal data.

7. Children's Privacy

The App is not directed at children under 13. We do not knowingly collect information from children.

8. Changes to This Policy

We may update this policy. Changes will be reflected on this page with an updated date. Continued use constitutes acceptance.

9. Contact

This is an open-source project. For questions, open an issue on GitHub or visit the About page.
